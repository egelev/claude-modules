# Security Policy

## Supported versions

Only the latest version published to npm is supported. Fixes ship in a new release rather than as
back-ports.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[**Report a vulnerability**](https://github.com/egelev/claude-modules/security/advisories/new)
form (Security tab → Advisories). Do not open a public issue for a suspected vulnerability.

Expect an acknowledgement within 7 days. Once a fix is ready it will be released and the advisory
published with credit to the reporter, unless anonymity is requested.
